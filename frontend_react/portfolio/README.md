# Pavan Ramagiri — Portfolio

Personal portfolio for my work across software engineering, distributed systems, and agentic AI.

**Live site:** [pavan9753.github.io/AI-agent-work-and-coding-profiles](https://pavan9753.github.io/AI-agent-work-and-coding-profiles/)

## Run locally

```bash
npm install
npm run dev
```

## Build and deploy

Build the copied project from this directory with:

```bash
npm run build
```

The Vite base path and `homepage` are configured for the original `AI-agent-work-and-coding-profiles` GitHub Pages site. To publish updates to that live site, use the app in the original repository and its **Settings → Pages** configuration (`gh-pages` branch, `/(root)`). The copy in this repository is for browsing and development; its deploy script would publish to this repository instead.

## Repository contents

- `src/` — React portfolio and responsive visual system
- `public/Pavan_R_SWE2.pdf` — downloadable résumé copy served by the site
- `public/Certificates/` — certificate copies shown on the site
